# Univmeeting - 전국 대학생 미팅

Univmeeting은,
전국 453개 대학교·캠퍼스 재학생이 **학번 및 재학증명서 인증**을 거쳐
주선자 없이 안전하게 미팅 방을 만들고 참여할 수 있게 도와줘요!

## 주요 기능
- **회원제**: 관리자 승인 완료 회원만 미팅 방 생성·참여 및 모집 글 작성·신청 가능
- **미팅 방 주선**: 전국 453개 대학 상대 지정, `2:2` / `3:3` / `4:4` 인원 매칭, 정원 충족 시 자동 성사 전환, 방장/관리자 방 삭제
- **전국 453개 대학 지도**: 권역별 필터, 실시간 모집 방 수 마커 표시, 대학별 방 모아보기
- **게시판**: `미팅 모집` / `팀원 구인` 글 작성, 팀 신청·취소, 작성자 모집 마감/재오픈 및 삭제
- **공유 딥링크**: 방·게시글 고유 링크(`?page=room-detail&room=...`) 복사 및 접속 즉시 해당 상세 페이지 진입
- 관리자 계정(`VITE_ADMIN_EMAIL`)으로 로그인하면 학생 서비스 화면과 완전히 분리된 관리자 전용 포털로 진입하여 재학증명서 심사, 전체 회원 인증 관리, 미팅 방·게시글 관리, 신고 및 1:1 문의를 처리합니다.
- 이메일·비밀번호 회원가입, 로그인, 로그아웃
- 학번 입력 + 재학증명서(이미지 자동 압축 / PDF) 업로드 및 운영팀 실시간 승인·반려

당신도 주선자 없이 미팅에 참여할 수 있다!
Univmeeting
